<summary><b>⚙️ Setup Notes (click to expand)</b></summary>

<br>

GitHub profile READMEs are plain sanitized Markdown/HTML — GitHub strips `<script>`, `<style>`, and CSS animations, so true interactive 3D/hover effects can't run here. Everything animated above is a **GIF or generated SVG**, which is the closest GitHub allows to motion and depth:

1. **Waving gradient banners & footer** — powered by `capsule-render`, already live, no setup needed.
2. **Typing effect headline** — powered by `readme-typing-svg`, already live.
3. **Animated contribution snake** — needs a GitHub Action. In your `sushantkumaryadav912/sushantkumaryadav912` repo, add `.github/workflows/snake.yml`:
   ```yaml
   name: Generate Snake
   on:
     schedule:
       - cron: "0 */6 * * *"
     workflow_dispatch:
     push:
       branches: [ main ]
   jobs:
     generate:
       runs-on: ubuntu-latest
       steps:
         - uses: Platane/snk@v3
           id: snake
           with:
             github_user_name: sushantkumaryadav912
             outputs: |
               dist/github-contribution-grid-snake-dark.svg?palette=github-dark
         - uses: crazy-max/ghaction-github-pages@v4
           with:
             target_branch: output
             build_dir: dist
           env:
             GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
   ```
   Once it runs once, the snake image above will render automatically.
4. **Contribution Summary block** — the `<!-- CONTRIBUTIONS_START -->` / `<!-- CONTRIBUTIONS_END -->` markers are made for a small script or Action that reads a `contributions.json` you maintain and rewrites the text between them. Happy to write that script if you want it.
5. **Trophy animation** — `animation=true` on `github-profile-trophy` gives a subtle reveal effect the first time the SVG loads.

</details>
